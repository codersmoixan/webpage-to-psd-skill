# webpage-to-psd 使用说明

将可在浏览器中渲染的网页转换为分层 Photoshop PSD。文字使用原生可编辑文字图层；可准确还原的纯色矩形色块使用原生可编辑形状图层；图片、图标、渐变和其他可见样式独立分层，并按页面模块放入真实的 Photoshop 图层组。每份 PSD 表示指定宽度下的一个静态页面状态。

## 在 Codex 中使用

在消息中调用 `$webpage-to-psd`，提供网页地址或本地静态项目路径，并说明目标页面。对于已有 HTML 项目，保留 CSS、JavaScript、图片和字体的原始目录结构。

示例：

```text
$webpage-to-psd 将 D:/网站项目/preview 中的 pages/about.html 生成 PSD。
```

```text
$webpage-to-psd 将 https://example.com/about 生成 PSD，按 1920 像素视口宽度、一倍输出。
```

```text
$webpage-to-psd 将这个项目的 about 页面生成 PSD，视口宽度 1920，放大两倍，保留可编辑文字。
```

以上三种调用都会被支持：第一种未指定宽度，使用默认的 1920 像素和一倍输出；第二种采用显式指定的视口宽度和默认一倍输出；第三种同时采用显式视口宽度与输出倍率。`1920` 只是缺省宽度，不是固定宽度；调用时可以指定其他正整数视口宽度。

如需特定轮播图片、年份、标签页、弹窗或移动端宽度，请在请求中明确指定。只提供一张截图不适合本技能，需要可渲染的页面或项目。

## 当前默认值

| 项目 | 默认行为 |
| --- | --- |
| 捕获宽度 | 未指定时默认 **1920 CSS 像素**；任何明确指定的正整数宽度优先 |
| 输出倍率 | **1 倍**；请求放大时可使用 2、3、4 倍 |
| 分辨率 | 横向、纵向均为 **72 PPI** |
| 页面范围 | 完整页面，包含页脚 |
| 页面状态 | 当前／默认静态状态，不主动切换交互内容 |
| 图层组织 | 一个页面模块一个图层组；优先采用模块可见标题命名 |
| 图层命名 | 按内容或编辑用途命名，不添加序号、atom ID 或 DOM 编号 |
| 本地项目 | 仅通过本机回环服务器渲染，不部署或上传项目 |

仅在调用未指定宽度时，才将浏览器 CSS 视口宽度设置为 1920 像素。显式宽度不会被改回 1920。浏览器视口宽度、页面内容宽度、输出倍率和 PPI 是独立概念。

例如：1920 × 6816 的捕获，一倍输出为 1920 × 6816，两倍输出为 3840 × 13632。修改 PPI 本身不会增加像素。当前脚本没有 `--ppi` 参数，采用 72 PPI；如需其他值，应同步调整导出配置、原生文字字号换算及验证。

浏览器滚动条可能占用内容宽度，技能会核对实际截图尺寸。仅当宽度和倍率都未指定时，PSD 才默认精确为 1920 像素宽；显式宽度按指定值输出，显式倍率再作用于该视口宽度。技能会明确处理滚动条差异，不会把较窄截图冒充目标宽度，也不会拉伸旧截图。

## 转换流程

1. 确定页面、视口宽度、倍率和静态状态。本地项目启动临时服务器，输出目录位于源项目之外。
2. 设置并验证浏览器视口，加载字体和可见图片；滚动加载延迟图片后回到目标位置。
3. 导出 DOM／样式、原始素材和整页参考图，并在截图前后比较页面结构，拒绝不稳定的捕获；同时识别页面模块及其标题。
4. 准备独立图层与黑白图集，在浏览器中按最终倍率直接渲染文字、SVG 和 CSS 样式。
5. 从项目原始文件构建图片图层，并把纯色背景、按钮、卡片、输入框、标签、分隔线和纯色伪元素导出为 Photoshop 原生矢量形状图层。形状保留填色、描边、尺寸和四个独立可编辑圆角；阴影或纹理等效果单独分层。
6. 按模块创建真实 Photoshop 图层组，将相关背景、标题、正文、图片、按钮和装饰图层放入同一组；组名优先采用模块标题，图层名采用内容或用途且不带编号。
7. 生成 PSD、预览和验证报告；回读 PSD，验证画布、PPI、模块组结构、无编号名称、文字内容与边界，以及原生形状的矢量路径、填色、描边和圆角数据，再独立合成图层并进行视觉检查。
8. 交付文件，停止本次临时服务器，恢复临时视口设置。

这不是把一张整页截图放进 PSD，也不是直接放大已有的一倍文字截图。符合条件的纯色色块若仍被导出为像素层，同样属于导出失败；仅把像素层命名为“形状”不算可编辑形状。图层平铺在根目录、模块组缺失或图层名称带自动编号也属于导出失败。缺失原始图片、缺失非空文字快取、错误图集尺寸或不稳定捕获都会阻止导出。

## 输出文件

| 文件 | 内容 |
| --- | --- |
| `*.psd` | 分层 Photoshop 文件 |
| `*_preview.png` | 导出的完整页面预览 |
| 交付说明文件 | 尺寸、倍率、字体、状态和已知限制；名称按任务确定 |
| `PSD_validation.json` | 图层与模块组计数、未分组图层、编号名称、原生文字、原生形状、形状栅格回退、PPI、字体选择与合成误差 |
| `image_provenance.json` | 图片原文件来源及任何回退记录 |
| `capture_dimensions.json` | 必需的视口／截图／倍率契约；准备阶段校验并补充最终画布尺寸 |
| `visual_qa/` | 缩略总览、原生像素局部和质量摘要 |

## 手动运行脚本

以下为维护者用法。脚本不能代替浏览器捕获步骤，也不提供单条命令自动完成所有转换。需要 Python、`Pillow`、`numpy`、`psd-tools`，以及支持 DOM 提取、视口设置、截图和素材导出的浏览器工具。Codex 优先使用其内置 Python 环境。

在技能目录下执行，示例中的项目和输出路径需替换为实际路径：

```powershell
# 启动本地项目，使用它报告的 URL；保持此进程运行到素材取得完毕。
python -X utf8 scripts/serve_static_project.py --project-dir 'D:/网站项目/preview' --entry 'pages/about.html' --job-dir 'C:/PSD作业'
```

按 [浏览器捕获规范](references/browser-capture.md) 生成 `web_dom.json`、`web_dom_after.json`、`web_reference.png`、`capture_dimensions.json` 和 `web_assets.json` 后：

```powershell
python -X utf8 scripts/check_capture_pair.py --job-dir 'C:/PSD作业'
python -X utf8 scripts/build_psd.py prepare --job-dir 'C:/PSD作业'
```

`prepare` 默认一倍；明确要求两倍时必须使用严格倍率模式：

```powershell
python -X utf8 scripts/build_psd.py prepare --job-dir 'C:/PSD作业' --render-scale 2 --strict-render-scale
```

随后用单独的回环服务器提供作业目录，在同一浏览器引擎中打开每个 `atlas_N_white.html` 和 `atlas_N_black.html`。按 `web_layers.json` 记录的宽度和高度设置视口，分别保存同名 PNG。确认所有图集尺寸和内容完整后执行：

```powershell
python -X utf8 scripts/build_psd.py build --job-dir 'C:/PSD作业' --template 'assets/text-template.psd' --output-name 'about.psd'
```

`build` 使用准备阶段记录的倍率，无需再次指定 `--render-scale`。标准 PSD 的单边限制为 30000 像素；明确请求的倍率须使用 `--strict-render-scale`，超限时不能静默缩小。

## 支持范围与限制

- 支持一个线性渐变叠加一个原始背景图片的独立拆层，并按捕获的伪元素顺序和 z-index 处理遮罩；复杂堆叠仍需视觉核对。
- 多重图片背景、混合模式和尚未支持的效果可能需要扩展直接渲染器。`--allow-image-raster-fallback` 仅用于已说明的复杂效果例外，不应作为日常默认参数。
- Canvas、视频或跨域嵌入内容可能使用局部栅格层，需在说明中标明。
- 纯色矩形主体即使带有阴影、纹理或图片，也应尽量拆出独立原生形状层；只有无法用 Photoshop 形状忠实表达的具体效果或几何部分才允许栅格化，并须记录原因。
- 原照片的像素数量限制实际细节，两倍导出不会创造新的照片细节。
- 编辑文字需要对应字体。字体替换会记录在报告中；浏览器和 PSD 回读验证不等于已在 Photoshop 内验证编辑和文字重排。
- 已编译的静态项目可直接使用。需要后端或构建过程的项目应先明确运行条件。
